# Page Monitor - 网页状态监控插件

监控网页上的状态变化（DOM、输入框、复选框、下拉框），匹配时发送系统通知，支持拦截按钮操作。

## 安装

1. 打开 `edge://extensions` 或 `chrome://extensions`
2. 开启「开发者模式」
3. 点击「加载解压的扩展」→ 选择 `chrome-page-monitor` 目录

## 快速上手

### 1. 创建监控规则

点击工具栏图标 → **「+ 新建」**：

- **规则名称**：如「生产任务监控」
- **目标 URL**：要监控的网页地址（默认包含匹配）

### 2. 添加 DOM 监控目标

每个规则可以添加多个目标，每个目标独立配置：

**元素类型**：

| 类型 | 监控内容 | 示例 |
|------|---------|------|
| 元素 | 出现/消失 + 可选文本过滤 | `.task-row` 出现时触发 |
| 复选框 | 勾选/未勾选 | `#agree` 已勾选时触发 |
| 输入框 | 值匹配 | `.amount` 值为 `0` 时触发 |
| 下拉框 | 选中值匹配 | `select` 选中 `失败` 时触发 |

**选择器获取方式**：

| 方式 | 操作 |
|------|------|
| 智能推荐 | 点「推荐」→ 自动扫描页面上状态相关元素 → 点选 |
| 可视化选取 | 点「选取」→ 在页面上悬停/点击元素，自动生成 CSS 选择器 |
| 手动输入 | 直接写 CSS 选择器 |

**值匹配规则**（输入框/下拉框）：

| checkValue | 匹配方式 |
|-----------|---------|
| 纯文本 | 严格相等 |
| 含 `.*+?^${}` 等 | 正则匹配 |

### 3. 触发拦截（可选）

配置按钮选择器 → 当用户点击该按钮时，先检查所有 DOM 目标：

- 有匹配 → **阻断按钮操作** + 通知
- 无匹配 → 按钮正常执行

### 4. 通知设置

- 通知方式：系统通知 / 声音 / 两者
- 冷却时间：两次通知的最小间隔（秒）
- **自定义模板**：可用变量 `{name}` `{selector}` `{text}` `{count}` `{url}`

### 5. 自动刷新（可选）

- **定时刷新**：每隔 N 秒自动刷新页面
- **点击按钮刷新**：自动点击页面上的刷新按钮
- **检测后自动点击**：检测到匹配时自动点击指定按钮
- 自动刷新触发的通知不受冷却限制

### 6. API 监控（可选）

截获 `fetch` / `XMLHttpRequest` 响应，匹配响应内容后发送通知。

## 状态变化检测

只在元素的状态或内容**发生变化**时才发送通知，避免重复打扰：

- 元素从无到有 → 通知
- 元素从有到无 → 通知（absence 模式）
- 元素内容变化 → 通知
- 页面刷新后状态重置 → 可以再次通知

## 注意事项

- 创建/修改规则后，目标页面可能需刷新
- 全局开关可以暂停所有监控
- 页面 Console 和 Service Worker Console 是两个独立的开发者工具

## 调试

1. **目标页面** F12 → Console，查找 `[PageMonitor]` 日志
2. **扩展页面** → 点击「Service Worker」→ 查看通知发送日志
