# Page Monitor - 网页状态监控插件

监控网页上的任务状态变化，当出现特定状态时发送系统通知。

## 安装

1. 打开 `edge://extensions` 或 `chrome://extensions`
2. 开启「开发者模式」
3. 点击「加载解压的扩展」→ 选择 `chrome-page-monitor` 目录

## 快速上手

### 1. 创建监控规则

点击工具栏图标打开弹窗 → **「+ 新建」**：

- **规则名称**：随便起个名，如「生产任务监控」
- **目标 URL**：要监控的网页地址（默认包含匹配，输入域名即可匹配该域名下所有页面）

### 2. 选择要监控的元素

三种方式任选：

| 方式 | 操作 |
|------|------|
| **智能推荐** | 点「推荐」→ 插件自动扫描页面上的状态元素 → 点选 |
| **可视化选取** | 点「选取」→ 在页面上悬停/点击目标元素，自动生成 CSS 选择器 |
| **手动输入** | 直接在 CSS 选择器输入框填写，如 `.status-pending` |

### 3. 设置通知

- **通知方式**：系统通知 / 声音 / 两者
- **冷却时间**：两次通知的最小间隔（秒），避免频繁打扰

### 4. 设置自动刷新（可选）

- **定时刷新**：每隔 N 秒自动刷新页面
- **点击按钮刷新**：自动点击页面上的刷新按钮 → 用「选取」按钮选择目标按钮

> 自动刷新触发的通知不受冷却时间限制

### 5. 检测后自动操作（可选）

勾选「检测到匹配时自动点击按钮」→ 用「选取」选择目标按钮。

当检测到状态匹配时，自动点击该按钮（如批量操作按钮），并立即发送通知。

### 6. 自定义通知内容（可选）

可用的模板变量：

| 变量 | 含义 |
|------|------|
| `{name}` | 规则名称 |
| `{selector}` | 匹配的 CSS 选择器 |
| `{text}` | 匹配元素的文本 |
| `{count}` | 匹配元素数量 |
| `{url}` | 当前页面 URL |

示例：`发现 {count} 个未完成任务：{text}`

## 注意事项

- 创建规则后**需要刷新目标页面**，监控才会生效
- 页面 Console 和 Service Worker Console 是**两个不同的**开发者工具窗口
- 如果没收到通知，先检查操作系统通知设置中 Edge/Chrome 的通知权限

## 调试

如果通知不工作，按以下顺序排查：

1. **目标页面** F12 → Console，看是否有 `[PageMonitor] Content script loaded` 日志
2. **目标页面** Console，看是否有 `[PageMonitor] check:` 日志
3. **扩展页面** `edge://extensions` → 点击「Service Worker」→ 看是否有 `[PageMonitor] Sending notification` 日志
